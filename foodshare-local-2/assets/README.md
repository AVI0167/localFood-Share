# Assets Folder

This folder contains all static assets for the FoodShare application.

## Directory Structure

```
assets/
├── images/
│   ├── logo.png
│   ├── banner.jpg
│   └── icons/
└── README.md
```

## Contents

### images/
- **logo.png** - Application logo
- **banner.jpg** - Hero banner image
- **icons/** - Application icons and icons for listings

## Usage

All images are referenced in the HTML files and CSS stylesheets. Update image paths if needed.
